## Feature 1: 信号融合分数分解弹窗

### 当前问题
用户看到最终分数 (如 72 分) 但不知道四维信号各贡献多少，
也不知道冲突惩罚和宏观调整的影响。

### 设计

```
┌─ 信号融合分解 ──────────────────────────────────────┐
│                                                      │
│  AAPL (US:AAPL)                    最终分数: 72.3    │
│                                                      │
│  ┌─ 加权分解 ──────────────────────────────────────┐ │
│  │                                                  │ │
│  │  人类信号    ████████████░░░░░   68 × 35% = 23.8│ │
│  │  技术信号    ██████████████░░░   82 × 25% = 20.5│ │
│  │  新闻信号    ██████████░░░░░░░   55 × 20% = 11.0│ │
│  │  估值信号    ████████████████░   90 × 20% = 18.0│ │
│  │                                ─────────────────│ │
│  │  加权小计                              = 73.3   │ │
│  │                                                  │ │
│  │  冲突惩罚    ⚠️ 人类-技术冲突           -5.0    │ │
│  │  宏观调整    📊 复苏期 → 股票 +3        +3.0    │ │
│  │  多信号一致  ✓ 3/4 信号一致             +1.0    │ │
│  │                                ─────────────────│ │
│  │  最终分数                              = 72.3   │ │
│  │                                                  │ │
│  └──────────────────────────────────────────────────┘ │
│                                                      │
│  行动推断: 分数≥72 且 信心≥58 → 建仓/加仓           │
│  信心: 64%  冲突: 1 项                               │
│                                                      │
└──────────────────────────────────────────────────────┘
```

### 触发方式
资产洞察面板的最终分数旁边添加 ℹ️ 图标，点击展开 Popover/Dialog。

### 实现文件
- `app/daa/dashboard/workbench/_components/FusionScoreBreakdown.tsx` (新建)
- 集成到资产表格的洞察区域

## Feature 2: 日/周 P&L 变化指标

### 当前问题
SummaryHeader 显示总权益，但不显示今日/本周/本月的变化量和百分比。
用户最关心的问题 "今天赚了还是亏了" 无法一眼看到。

### 设计

```
┌─ Summary Header ─────────────────────────────────────────────────┐
│                                                                   │
│  ┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────┐│
│  │ 总权益       │ │ 持仓价值     │ │ 可用现金     │ │ 冻结资金 ││
│  │ ¥125,000     │ │ ¥98,500      │ │ ¥24,500      │ │ ¥2,000   ││
│  │              │ │              │ │              │ │          ││
│  │ 今日 +¥320   │ │              │ │              │ │          ││
│  │   ▲ +0.26%   │ │              │ │              │ │          ││
│  │ 本周 -¥1,200 │ │              │ │              │ │          ││
│  │   ▼ -0.95%   │ │              │ │              │ │          ││
│  └──────────────┘ └──────────────┘ └──────────────┘ └──────────┘│
│                                                                   │
└───────────────────────────────────────────────────────────────────┘
```

### 数据来源
- `daa_equity_snapshots` 表已有历史权益快照
- 今日变化 = 当前 totalEquity - 最近一次非今日快照
- 本周变化 = 当前 totalEquity - 本周一快照
- 涨跌颜色: 绿色(emerald)/红色(red)

### 实现文件
- 后端: `src/daa/modules/read/workbenchReadService.ts` 添加 `equityDelta` 计算
- 前端: `WorkbenchSummaryHeader.tsx` 在总权益卡片下方添加涨跌行

## Feature 3: 基准对比叠加图

### 当前问题
权益曲线图只显示总权益绝对值，无法判断是因为大盘涨了还是自己选股好。
缺少 vs SPY 和 vs 60/40 组合的基准对比。

### 设计

```
┌─ 投资组合表现 ──────────────────────────────────────────────┐
│                                                              │
│  时间范围:  [1M] [3M] [6M] [1Y] [全部]                      │
│                                                              │
│  120% ┤                                                      │
│       │                     ╱╲    ── 我的组合 (+12.3%)       │
│  115% ┤                   ╱    ╲╱  ── SPY (+8.7%)           │
│       │                 ╱          ·· 60/40 (+5.2%)         │
│  110% ┤              ╱╱                                      │
│       │           ╱╱╱  ·····                                 │
│  105% ┤        ╱╱  ···                                       │
│       │     ╱╱···                                            │
│  100% ┼──╱···─────────────────────────────────── 时间        │
│       │                                                      │
│  95%  ┤                                                      │
│       └──────────────────────────────────────────────────    │
│       Jan    Feb    Mar    Apr    May    Jun                  │
│                                                              │
│  超额收益: +3.6% vs SPY  |  +7.1% vs 60/40                 │
│  跟踪误差: 4.2%          |  最大回撤: -3.8%                 │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 数据来源
- 组合: `daa_equity_snapshots` (已有)
- SPY: `daa_asset_price_history` (SPY 历史价格已有)
- 60/40: 计算 0.6×SPY + 0.4×BND (两者价格已有)
- 归一化为基期 = 100%

### 实现文件
- 后端: `src/daa/modules/portfolio/benchmarkComparison.ts` (新建)
- 前端: `app/daa/dashboard/workbench/_components/PerformanceChart.tsx` (新建)
- 集成到 CockpitSection 替换现有简单 AreaChart

### 当前问题

工作台主页没有实时风险概览。

### 设计

```
┌─ 组合风险概览 ───────────────────────────────────────────────┐

│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────────┐ │
│  │ HHI 集中度│  │ 最大单仓 │  │ 最大回撤 │  │ 漂移状态     │ │
│  │          │  │          │  │          │  │              │ │
│  │  0.082   │  │  15.2%   │  │  -3.8%   │  │ 2 项超阈值  │ │
│  │  ●●●○○   │  │  AAPL    │  │  本月     │  │              │ │
│  │  适度集中 │  │  ⚠ 接近15%│  │  ✓ 正常  │  │ ⚠ 需关注    │ │
│  └──────────┘  └──────────┘  └──────────┘  └──────────────┘ │
│                                                               │
│  ┌─ 目标 vs 实际权重 ──────────────────────────────────────┐ │
│  │                                                          │ │
│  │  AAPL  目标 10%  ████████████████░░░░  实际 15.2% ⚠️    │ │
│  │  MSFT  目标 8%   ████████████░░░░░░░  实际 9.1%         │ │
│  │  SPY   目标 20%  ████████████████████  实际 18.5%       │ │
│  │  GLD   目标 10%  █████████░░░░░░░░░░  实际 7.3%  ↓     │ │
│  │  BND   目标 15%  ███████████████░░░░  实际 12.0%        │ │
│  │  现金  目标 5%   ████████████████████  实际 19.6% ⚠️    │ │
│  │                                                          │ │
│  └──────────────────────────────────────────────────────────┘ │
│                                                               │
└───────────────────────────────────────────────────────────────┘
```

### 数据来源
- HHI: 各持仓 weight² 之和 (前端纯计算)
- 最大单仓: max(position.weight)
- 最大回撤: 从 `daa_equity_snapshots` 峰值计算
- 漂移: `driftSnapshot` 已在 RebalanceCycle 中
- 目标权重: `daa_target_allocations` 表

### 实现文件
- 前端: `app/daa/dashboard/workbench/_components/PortfolioRiskPanel.tsx` (新建)
- 集成到 CockpitSection 作为可折叠面板

## Feature 5: 加载骨架屏

### 当前问题
大部分面板在数据加载时显示空白或文字 "loading"，
缺少骨架屏导致页面跳动 (CLS) 和用户体验不连贯。

### 设计

```
加载中状态:

┌─ Summary Header (骨架) ──────────────────────────────────────┐
│  ┌──────────────┐ ┌──────────────┐ ┌──────────────┐         │
│  │ ████████     │ │ ████████     │ │ ████████     │         │
│  │ ██████████░░ │ │ ██████████░░ │ │ ██████████░░ │  ← 闪烁 │
│  └──────────────┘ └──────────────┘ └──────────────┘         │
└──────────────────────────────────────────────────────────────┘

┌─ 权益曲线 (骨架) ───────────────────────────────────────────┐
│                                                              │
│  ████████████████████████████████████████████████████░░░░░░  │
│  ██████████████████████████████████████████░░░░░░░░░░░░░░░  │
│  ████████████████████████████████░░░░░░░░░░░░░░░░░░░░░░░░  │
│  ██████████████████████░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░  │
│                                                    ← 渐变波 │
└──────────────────────────────────────────────────────────────┘

┌─ 指标卡片 (骨架) ────────────────────────────────────────────┐
│  ┌────────┐  ┌────────┐  ┌────────┐                         │
│  │ █████  │  │ █████  │  │ █████  │                         │
│  │ ██░░░░ │  │ ██░░░░ │  │ ██░░░░ │  ← 3列网格保持布局     │
│  │ ████░░ │  │ ████░░ │  │ ████░░ │                         │
│  └────────┘  └────────┘  └────────┘                         │
└──────────────────────────────────────────────────────────────┘
```

### 骨架类型
| 区域 | 骨架形状 | 动画 |
|------|---------|------|
| 指标卡片 | 标题+数值+进度条 矩形 | animate-pulse |
| 权益曲线 | 波浪形 SVG path | shimmer 渐变 |
| 饼图 | 圆形 + 扇形分割 | animate-pulse |
| 提案列表 | 3 行卡片形状 | animate-pulse |
| 聊天消息 | 对话气泡形状 | animate-pulse |

### 实现文件
- `app/daa/dashboard/_components/SkeletonPatterns.tsx` (新建 — 5 种骨架组件)
- 修改各面板组件: 在 `loading` 状态时渲染骨架而非空白
