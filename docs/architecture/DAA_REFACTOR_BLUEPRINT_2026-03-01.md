# DAA 重构蓝图（当前基线）

> 状态：Accepted  
> 生效日期：2026-03-01  
> 适用范围：`/daa` 单组合系统（建议 + 人工交易事件记录）

## 1. 当前目标与原则

- 以**资金池（现金）**为起点，支持零持仓启动。
- 以**三维信号**（基金经理持仓 + 新闻 + 技术）驱动候选机会。
- 统一链路为：`资产首页 -> 持仓配置 -> 运行决策 -> 交易执行事件`。
- 系统只给建议与风控解释，不自动下单。

## 2. 当前已实现能力

### 2.1 资金池与候选池

- 策略账户支持：`baseCurrency / cash / investableCash / frozenCash`。
- 新增候选池存储与页面：`/daa/dashboard/watchlist`。
- 支持现金起步：候选标的可自动参与建仓建议。

### 2.2 三维信号融合（A+）

- 人因信号：基金池采集链路 + 分层决策。
- 新闻信号：情绪词、来源可信度、时效衰减。
- 技术信号：SMA20/SMA60/RSI14/20日收益/波动率。
- 融合层支持：权重归一 + 冲突惩罚 + 置信度计算。

### 2.3 多币种与 FX

- 新增 `daa_fx_rates` 与手工维护入口（设置页）。
- 估值统一换算到 `baseCurrency`。
- 增加 FX 覆盖率与时效覆盖率监控。
- FX 缺失/过期时，阻断非基准币种 BUY（护栏生效）。

### 2.4 LLM 二次分析

- 已接入 `llm_analysis` 数据源配置。
- 支持 `codex / packycode / openai-like` Provider。
- 二次分析只输出解释与风险提示，不参与自动执行。

## 3. 用户操作流程（推荐）

1. 在“策略配置”设置基准币种与资金池。
2. 在“候选池”维护可评估标的。
3. 在“人因中心”执行采集并刷新信号。
4. 回到“资产首页”或“策略配置”运行统一决策。
5. 在“风控审计”复核阻断原因与告警。
6. 在“交易执行”页面按 submit/fill/cancel/skip 记录成交事件。

## 4. 当前约束与已知边界

- 仍为单组合模式，不含多账户组合管理。
- 不提供自动下单，只支持人工交易事件记录。
- 数据覆盖以 yfinance + 基金池信号为主，资产主数据体系仍可继续增强。
