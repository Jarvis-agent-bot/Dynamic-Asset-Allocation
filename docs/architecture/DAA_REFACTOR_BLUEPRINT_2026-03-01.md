# DAA 重构蓝图（当前基线）

> 状态：Accepted  
> 生效日期：2026-03-01  
> 适用范围：`/daa` 单组合系统（建议 + 人工交易事件记录）

## 1. 当前目标与原则

- 以**资金池（现金）**为起点，支持零持仓启动。
- 以**三维信号**（基金经理持仓 + 新闻 + 技术）驱动资产机会。
- 统一链路为：`资产首页 -> 交易工作台（资产发现/洞察/下单） -> 批量执行与回执`。
- 系统只给建议与风控解释，不自动下单。

## 2. 当前已实现能力

### 2.1 资金池与资产宇宙

- 策略账户支持：`baseCurrency / cash / investableCash / frozenCash`。
- 资产主表统一持仓与观察资产（`watch_enabled` + `holding_qty` 双状态）。
- 工作台主入口：`/daa/dashboard/portfolio`。
- 支持现金起步：观察资产可自动参与建仓建议。

### 2.2 三维信号融合（A+）

- 人因信号：基金池采集链路 + 分层决策。
- 新闻信号：情绪词、来源可信度、时效衰减。
- 技术信号：SMA20/SMA60/RSI14/20日收益/波动率。
- 融合层支持：权重归一 + 冲突惩罚 + 置信度计算。

### 2.3 多币种与 FX

- 新增 `daa_fx_rates` 与手工维护入口（设置页）。
- 估值统一换算到 `baseCurrency`。
- 增加 FX 覆盖率与时效覆盖率监控。
- FX 缺失/过期时，阻断非基准币种 BUY（护栏生效）。

### 2.4 LLM 二次分析

- 已接入 `llm_analysis` 数据源配置。
- 支持 `codex / packycode / openai-like` Provider。
- 二次分析只输出解释与风险提示，不参与自动执行。

## 3. 用户操作流程（推荐）

1. 在“系统设置”配置基准币种、数据源和策略参数。
2. 在“交易工作台”搜索资产并加入资产宇宙。
3. 在“人因中心”执行采集并刷新信号。
4. 在“交易工作台”运行策略建议并查看洞察/风险提示。
5. 将建议或手动订单加入交易篮子，批量执行。
6. 在回执区复盘成功/失败原因并回溯资产详情。

## 4. 当前约束与已知边界

- 仍为单组合模式，不含多账户组合管理。
- 不提供自动下单，仅支持模拟交易执行。
- 风险提示策略为“提示不阻断”，执行阶段再做现金/仓位/汇率硬校验。
- 数据覆盖以 yfinance + 基金池信号为主，资产主数据体系仍可继续增强。
